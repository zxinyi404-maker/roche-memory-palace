# Roche 记忆宫殿 v9.0.1

七房间记忆管理系统。它把 Roche 的长期记忆整理成房间、事件和关联边，再用保持率、混合检索、角色性格和当前情绪决定每轮聊天更容易想起什么。

## 功能

### 七个房间

- 客厅：日常闲聊和近期互动，容量 200 条，衰减最快。
- 卧室：亲密情感和深层羁绊，长期保存。
- 书房：工作、学习和技能成长。
- User 的房间：用户信息、习惯和偏好。
- 自我房间：角色身份认知和演变，永久保留。
- 阁楼：未消化的困惑和潜意识片段，永久保留并可参与反刍。
- 窗台：期盼、目标和未来憧憬，七天未完成会成为心理锚点。

客厅超过 200 条时，重要片段会晋升卧室，普通片段会沉入阁楼。迁移只保存在插件元数据中，不会悄悄改写 Roche 原始记录。

### 混合检索

- 85% 语义 + 15% BM25：语义匹配负责含义，关键词匹配保留具体词带来的现实感。
- 关联扩散：沿语义、情绪、时间、房间和因果边扩散两跳。
- 性格偏好：情感型偏向情绪边，叙事型偏向时间边，意象型偏向画面联想，分析型偏向因果边。
- 情绪启动：当前情绪与记忆情绪匹配时，该记忆会获得 1.3 倍加权。
- 反刍检查：按角色反刍倾向，以 20% 乘数计算随机侵入性念头。

Roche 当前公开插件 API 提供 memory.getLongTerm() 和文本 memory.search()，没有公开的向量查询或 embedding 接口。插件会把 Roche 的向量记录作为数据源，并提供 OpenAI-compatible 嵌入接口配置；未配置时使用浏览器本地语义近似，不把文本交集冒充成原生向量搜索。

### 自动遗忘

每条可衰减记忆使用 R = e^(-t/S) 计算保持率。S 会受房间、重要性、情绪强度和复习次数影响。复习会按质量重新计算稳定度和下一次复习时间。

自动遗忘会：

- 更新保持率、褪色状态和待复习时间。
- 将客厅溢出的记忆迁移到卧室或阁楼。
- 将已实现、落空或已经消化的窗台和阁楼内容迁移到合适房间。
- 在遗忘中心列出低保持率记忆。

它不会自动删除 Roche 记忆。只有低保持率、低重要性的项目才会进入待确认删除列表，并且必须通过 Roche 的二次确认弹窗后才调用 memory.delete。

### 页面

- 角色选择：每个角色独立拥有自己的七房间。
- 记忆宫殿：房间分区、统计、搜索、事件盒、遗忘曲线和检索设置。
- 房间详情：查看完整记忆、保持率、标签和关联记忆。
- 事件盒：按时间和关联聚合重要记忆。
- 记忆详情：编辑房间、重要性、情绪、标签和备注，并可复习强化。
- 遗忘中心：查看褪色、待复习和待确认删除的记忆。

## Roche 聊天桥

插件使用 Roche 的 contextProvider 在每轮聊天前生成内部记忆上下文，不额外调用主聊天模型。主模型可以按需调用：

- search_memory：按当前角色搜索记忆。
- save_memory：保存确实有长期价值的新事实、关系节点或期盼。
- review_memory：强化被再次确认或自然回忆的记忆。

上下文要求角色自然表达，不暴露房间、分数、检索过程，也不会把不确定内容当成事实。

在 Roche 插件管理页面安装以下 manifest：

https://raw.githubusercontent.com/zxinyi404-maker/roche-memory-palace/main/manifest.json

当前版本：9.0.1

## 权限与数据

插件需要读取角色、会话和记忆，使用 storage、UI 以及 memory:write。增强元数据保存于插件隔离存储：

memoryPalaceMeta:{conversationId}
memoryPalaceState:{conversationId}
memoryPalaceEmbeddingConfig

卸载或清除插件存储不会删除 Roche 主记忆。嵌入接口地址、模型和 API Key 也只保存在本插件的隔离存储中。
