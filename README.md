# 🧠 Roche 记忆宫殿

基于艾宾浩斯遗忘曲线的深度记忆管理系统，让你的 AI 伴侣拥有真正的长期记忆。

## ✨ 核心功能

### 1. 艾宾浩斯遗忘曲线系统
- **智能衰减算法**：`R = e^(-t/S)`，根据时间自动计算记忆保持率
- **重要性分级**：5个等级（琐事/一般/重要/关键/刻骨铭心）
- **情绪增强**：情绪越强烈的记忆衰减越慢（0-5级）
- **智能巩固**：每次复习自动增强记忆强度

### 2. 记忆分类系统
- 📌 **事实**：基本信息、客观事实
- 🎬 **经历**：发生过的事件、经历
- ⚡ **技能**：掌握的能力、技能
- 💫 **关系**：人物关系、社交网络
- 📚 **知识**：学到的知识、概念
- ❤️ **情感**：情绪、感受、情感体验

### 3. 智能分析
- **自动分类**：根据文本内容智能判断记忆类型
- **重要性识别**：根据关键词自动判断重要程度
- **情绪检测**：识别文本中的情绪强度

### 4. 可视化面板
- 📊 **仪表盘**：总览记忆统计、分布、健康度
- 📅 **时间轴**：按时间排列的记忆流
- 🕸️ **关联图**：记忆之间的连接网络（开发中）
- 🔄 **复习中心**：自动识别需要巩固的记忆

### 5. 向量检索（利用 Roche 原生能力）
- 语义搜索：根据含义查找相关记忆
- 相似推荐：发现相关联的记忆

## 📦 安装方法

### 1. 在 Roche 中安装插件

在 Roche 插件管理页面，输入以下链接：

```
https://raw.githubusercontent.com/zxinyi404-maker/roche-memory-palace/main/manifest.json
```

- ✅ 读取用户人设

- ✅ 读取会话列表
- ✅ 读取记忆

- ✅ 调用 AI

- ✅ UI 交互

## 🎯 使用指南

### 仪表盘
- 查看总记忆数、平均保持率
- 了解需要复习的记忆数量
- 查看记忆类型分布
- 浏览最近的记忆

### 时间轴
- 按时间顺序查看所有记忆
- 点击记忆卡片查看详情
- 记忆强度用彩色进度条显示

### 复习中心
- 自动筛选保持率低于 30% 的记忆
- 点击记忆卡片即可巩固（复习）
- 复习后记忆强度自动增强

### 记忆增强元数据

插件会为每条记忆添加增强信息：
- **重要性**（1-5）：决定记忆的基础强度和衰减速度
- **情绪强度**（0-5）：情绪越强，记得越牢
- **记忆类型**：自动分类或手动标记
- **复习次数**：每次复习都会增强记忆
- **关联记忆**：记录与其他记忆的连接
- **标签**：自定义标签
- **备注**：额外说明

## 🧮 算法原理

### 遗忘曲线公式

```
R = e^(-t/S)
```

- **R**：记忆保持率（0-1）
- **t**：时间流逝（天）
- **S**：记忆强度（由重要性、情绪、复习次数决定）

### 记忆强度计算

```
S = 基础强度 + 情绪加成 + 复习次数 × 0.5
```

| 重要性 | 基础强度 | 强度下限 | 复习增强系数 |
|--------|----------|----------|--------------|
| 琐事 | 1 | 0 | 1.2 |
| 一般 | 3 | 0.1 | 1.5 |
| 重要 | 7 | 0.3 | 2.0 |
| 关键 | 15 | 0.5 | 2.5 |
| 刻骨铭心 | 30 | 0.7 | 3.0 |

| 情绪强度 | 强度加成 |
|----------|----------|
| 中性 | 0 |
| 平静 | 0.5 |
| 愉悦 | 1 |
| 激动 | 2 |
| 强烈 | 4 |
| 极致 | 8 |

### 复习机制

每次复习：
- 更新 `lastRecall` 为当前时间
- `reviewCount` +1
- `strength` × `reinforceFactor`

## 📂 数据存储

### Roche Storage
- `selectedConversation`：当前选中的会话 ID
- `memoryMeta:{conversationId}`：该会话的记忆增强元数据

### 数据结构示例

```json
{
  "memory-id-123": {
    "lastRecall": 1722000000000,
    "reviewCount": 3,
    "importance": 4,
    "emotion": 2,
    "type": "experience",
    "relatedMemories": ["memory-id-456", "memory-id-789"],
    "pinned": false,
    "tags": ["生日", "重要"],
    "notes": "这是一个重要的生日记忆"
  }
}
```

## ⚠️ 注意事项

### 数据安全
- 插件使用 `roche.storage` 保存增强元数据
- 卸载插件会删除元数据，但不会删除 Roche 主记忆
- 建议定期导出备份（功能开发中）

### 性能建议
- 记忆数量 < 1000 时性能最佳
- 大量记忆时可能需要分页（待优化）

### 兼容性
- 需要 Roche 支持 `conversation.list()` API
- 需要 Roche 支持 `memory.getLongTerm()` API
- 向量记忆功能依赖 Roche 配置
